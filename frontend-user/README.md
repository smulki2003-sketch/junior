# Frontend User App

Phase 14 implementation: React + Tailwind student-facing app.

## Run
1. Copy `.env.example` to `.env`
2. `npm install`
3. `npm run dev`

## Build
- `npm run build`

## Test
- `npm run test`

## Structure
- `src/components`
- `src/pages`
- `src/services`
- `src/styles`
- `src/api`
- `src/store`
- `src/animations`
- `src/hooks`
- `src/utils`
